Política de privacidade

Última atualização: 7 de outubro de 2026

Resumo

O Desfundo não coleta, não armazena em servidores e não transmite seus dados pessoais nem suas imagens. Todo o processamento acontece no seu computador.

O app Desfundo

  • Imagens: as fotos e PDFs que você abre são processados apenas no seu computador. Nenhuma imagem é enviada para a internet, nem para nós.
  • Rede: o app não faz conexões de rede durante o uso. O modelo de inteligência artificial vem dentro do app, e ele funciona sem internet. A única exceção é o botão "Verificar atualizações" da versão portátil: só quando você clica, o app consulta no GitHub qual é a versão mais recente, sem enviar nenhum dado seu. Links que você clicar (site, doações, código-fonte) abrem no seu navegador.
  • Armazenamento local: para economizar memória, resultados em processamento podem ser guardados temporariamente no armazenamento interno do app, no próprio computador. Esses dados são apagados quando o app é aberto novamente. A escolha de idioma (PT/EN) também fica salva localmente.
  • Sem conta, sem análise de uso: não há cadastro, anúncios, telemetria nem rastreamento.

Este site

  • O site não usa cookies nem ferramentas de análise ou rastreamento.
  • Ele é hospedado no GitHub Pages. O GitHub pode registrar dados técnicos de acesso (como o endereço IP), conforme a política de privacidade do GitHub.
  • Para mostrar o número de downloads, o seu navegador consulta a API pública do GitHub.
  • A escolha de idioma do site fica salva apenas no seu navegador.

Doações

Doações via Pix, PayPal ou GitHub Sponsors são processadas por esses serviços, de acordo com as políticas de cada um. O Desfundo não recebe nem guarda dados de pagamento.

Contato

Dúvidas sobre privacidade: escreva para desfundo@outlook.com ou abra um tópico em github.com/desfundo/desfundo/discussions.
